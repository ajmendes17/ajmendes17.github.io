The problem

Manufacturing information lives across systems. Costpoint holds manufacturing orders, parts, and purchasing data; Epsilon3 tracks procedures, runs, and operator sign-offs. Program managers need a traceable picture of progress without manually searching through each system.

What we’re working toward

Our four-person student team is improving the integration service between these tools. The aim is to help ACME identify work that needs attention and give managers trustworthy information about production.

My current focus

My technical focus is organizing Epsilon3 sign-off records into a run-step timeline, calculating elapsed durations, and exposing that information through an API and Grafana. As client liaison, I also consolidate questions and updates so the team’s work stays connected to client feedback.

Being precise about progress

This is an active development project. Elapsed time between completion events is not the same as hands-on labor time. Dashboard work, broader alerts, and other proposed workflows should be understood as development goals, with scope and live validation still evolving.
