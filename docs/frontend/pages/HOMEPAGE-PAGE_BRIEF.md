# Homepage Page Brief

## Current direction

- Public portfolio homepage for recruiters, technical reviewers, and collaborators.
- Landscape desktop is the first layout target; CSS breakpoints keep narrower and portrait views readable.
- Keep the existing editorial hero and featured Manufacturing Integration card.
- Show project hierarchy as a 1–2–3 tower: Manufacturing Integration; Secure Chat and Local Learning Studio; ClueGame, MarketPulse AI, and Call for Fire Trainer.
- Keep each project title, short purpose, category, and normal link available in the document.
- Use fine hairline boundaries around project cards and softly fade the edge of concept artwork into the paper background.
- Label Local Learning Studio as in development. Its page is a personal project overview, not a hosted multi-user product.
- Use concept artwork only where the homepage does not have a suitable project screenshot; do not imply unverified implementation or results.

## Interaction direction

- This pass establishes card proportions, spacing, and visual hierarchy only.
- Future refinement may bring one card forward on hover or keyboard focus and gather the set into a single composition.
- Keep project navigation independent from animation. Respect reduced motion and provide a static presentation.

## Responsive behavior

- Wide desktop: featured card followed by two cards and then three cards.
- Medium viewport: two-column supporting grid.
- Narrow viewport: single-column cards with project purpose and links visible without hover.
