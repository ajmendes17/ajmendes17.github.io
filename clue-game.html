What it demonstrates

A full desktop game built from domain rules.

ClueGame is a custom Java implementation of Clue that turns external data files into a playable board. The project models rooms, walkways, doors, secret passages, occupied spaces, player hands, suggestions, accusations, and the hidden solution.

The complexity is in the rule coordination: board topology, movement targets, turn progression, card knowledge, and GUI state all have to stay consistent as human and computer players interact with the game.

Core systems

Where the engineering depth shows

01

Config Parsing

Board layout and setup files define rooms, spaces, weapons, players, labels, centers, doors, and secret passages.

02

Movement Search

Adjacency lists and recursive target calculation enforce dice rolls, room entry, blocked cells, and legal destinations.

03

Deduction Model

The game selects a hidden solution, deals the remaining deck fairly, and resolves suggestions in player order.

04

Computer Turns

Computer players prioritize unseen rooms and build suggestions from cards they have not already seen.
