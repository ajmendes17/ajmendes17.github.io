01 / THE STUDY LOOP

Learning is a loop, not a pile of notes.

Start with a topic or course source. Study it, try a question, see feedback, and return for review. LLS connects the steps so learners can see what they worked on and what might help next.

02 / THE KNOWLEDGE BASE

One brain for a whole class.

LLS can export a linked class knowledge base to Obsidian, connecting courses, topics, sources, assessments, and progress in a graph you can explore.

The app remains the study workspace. Obsidian is an optional, one-way export; refreshes preserve learner-authored sections in exported notes.

03 / MAPS & LESSONS

See the shape of a course. Then work through an idea.

LLS can propose a reviewable course map of modules, concepts, prerequisites, objectives, and assessments. Learners can study a topic or source with saved lessons that include explanations, analogies, worked examples, and knowledge checks.

04 / PRACTICE & EVIDENCE

Every attempt adds context.

Practice records answers, confidence, hint use, and feedback. Progress views show activity and recent results, and recall reviews can be suggested at 1-, 3-, and 7-day intervals. These signals help guide review; they are not calibrated mastery estimates.

AnswerConfidenceHintsFeedbackRecall

05 / LOCAL ARCHITECTURE

Personal data, on your machine.

The web interface, local service, and SQLite database work together to store course files and learner records locally by default. For AI-supported tasks, the local service uses the learner’s authenticated Codex installation and validates structured results before saving them.

React / TypeScript↔Fastify local service↔SQLite

Course data is stored locally. AI model processing uses cloud models through the authenticated Codex installation.

06 / STATUS & NEXT

IN DEVELOPMENT

A personal tool, growing one learning loop at a time.

Local Learning Studio is an actively developed personal application, not a hosted multi-user platform. Current boundaries include no scanned-document OCR, no calibrated mastery estimates, and one-way Obsidian export.

Next, the project can keep strengthening the course-to-practice loop and make its progress signals more useful while keeping their limits transparent.
